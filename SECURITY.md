# Kebijakan keamanan

NusaRiksa belum memiliki rilis produksi. Jangan gunakan data bank, data nasabah, atau kredensial asli.

Untuk laporan kerentanan, gunakan pelaporan privat GitHub apabila tersedia. Jangan memasukkan kode eksploit atau data sensitif dalam isu publik.

Sebelum rilis produksi, sistem harus memiliki autentikasi, pengendalian akses, pengamanan sesi, perlindungan data, manajemen kunci, audit log, pengujian pemulihan cadangan, serta telaah keamanan independen. Keamanan tidak dapat dibuktikan hanya dari penggunaan algoritma enkripsi.
