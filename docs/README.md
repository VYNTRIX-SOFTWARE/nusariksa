# Dokumentasi NusaRiksa

Mulai dari dokumen yang sesuai dengan pekerjaan Anda. Petugas bank tidak perlu membaca panduan developer untuk menggunakan aplikasi.

| Pembaca | Dokumen | Kegunaan |
| --- | --- | --- |
| Petugas TI, kepatuhan, dan pemeriksa | [Panduan Penggunaan](PANDUAN-PENGGUNA.md) | Langkah penggunaan aplikasi, pencatatan, peninjauan, dan unduhan laporan internal |
| Administrator server | [Operasional](OPERATIONS.md) | Instalasi, upgrade, pemeriksaan database, dan penanganan kegagalan |
| Administrator dan tim uji | [Kesiapan Pilot](PILOT-READINESS.md) | Pemeriksaan lingkungan, daftar skenario UAT, dan dasar keputusan uji terbatas |
| Administrator database | [Pemulihan](RECOVERY.md) | Uji restore PostgreSQL serta verifikasi bukti terenkripsi |
| Developer dan kontributor | [Pengembangan](DEVELOPMENT.md) | Struktur source, konfigurasi pengembangan, dan pengujian |
| Petugas kepatuhan dan peninjau instrumen | [Referensi PADK](PADK.md) | Ruang lingkup kertas kerja maturitas siber dan status verifikasi instrumen |
| Peninjau regulasi | [Matriks Ketentuan](MATRIKS-KETENTUAN-PENILAIAN-KEAMANAN-SIBER.md) | Rujukan peraturan, status interpretasi, dan batas penggunaan hasil |
| Maintainer produk | [Prinsip Produk](PRODUCT-DEFAULTS.md) | Keputusan desain, perilaku bawaan, dan batasan data yang dihasilkan aplikasi |

Untuk pengenalan produk dan instalasi singkat, kembali ke [README utama](../README.md). Kontribusi mengikuti [CONTRIBUTING.md](../CONTRIBUTING.md); laporan kerentanan mengikuti [SECURITY.md](../SECURITY.md).

Dokumentasi menjelaskan perilaku perangkat lunak pada versi yang digunakan. Penilaian dan bukti faktual menjadi tanggung jawab lembaga; kertas kerja PADK yang belum diverifikasi independen tidak dapat diperlakukan sebagai hasil resmi.
